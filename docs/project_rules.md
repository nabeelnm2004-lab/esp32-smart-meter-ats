# Project Rules

- Never break existing functionality.
- Preserve backward compatibility.
- Do not remove features unless requested.
- Integrate new features into the existing architecture.
- Avoid unnecessary refactoring.
- Preserve saved Preferences.
- Preserve GPIO assignments.
- Validate configuration before saving.
- Handle unexpected power loss safely.
- Keep dashboard and firmware synchronized.
- One feature should not negatively impact another.
- Explain any breaking changes before implementation.
