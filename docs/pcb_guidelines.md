# PCB Design Guidelines

## Safety

- Isolate AC and DC sections.
- Maintain proper creepage and clearance.
- Add fuse protection where appropriate.
- Add surge protection (MOV).
- Add TVS diode when required.
- Add reverse polarity protection.

## Layout

- Keep relay traces wide.
- Separate analog and digital circuits.
- Place decoupling capacitors near ICs.
- Keep high-current traces short.

## Components

- Label all connectors.
- Label GPIO pins.
- Add programming header.
- Add Reset button.
- Add Boot button.
- Add Power LED.
- Add Status LED.
- Add test points.
- Add mounting holes.
- Add silkscreen labels.

## Reliability

- Minimize EMI.
- Keep RTC battery away from heat sources.
- Protect communication lines.
