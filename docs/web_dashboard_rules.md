# Web Dashboard Rules

- Separate HTML, CSS and JavaScript.
- Keep UI responsive.
- Support desktop and mobile.
- Validate all user input.
- Use JSON for API communication.
- Keep API endpoints consistent.
- Display meaningful error messages.
- Show loading indicators when necessary.
- Avoid duplicate JavaScript.
- Use semantic HTML.
- Keep CSS organized.
- Minify assets only for production.
- Keep UI consistent.
- Maintain accessibility where practical.
